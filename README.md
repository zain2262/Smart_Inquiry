
# SmartInquiry

**Customer Inquiry Classification & Draft Replies**

## Project Overview
SmartInquiry is a beginner-friendly Python project that accepts customer inquiries, classifies them into categories, and prepares editable reply drafts for human review.

## Categories
- Pricing
- Order
- Support
- Other/Uncertain

## Safety
- Replies require human review.
- The system does not automatically send replies.
- Unclear inquiries should be flagged for review or clarification.

## Technology
- Python
- Streamlit
- Git

## Run Locally
1. Activate the Python virtual environment.
2. Install Streamlit: `python -m pip install streamlit`
3. Run: `python -m streamlit run app.py`
